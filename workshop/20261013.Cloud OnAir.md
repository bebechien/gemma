## PCでGemma 4をローカル環境で試す方法

用途や好みのインターフェースに合わせて、最適な実行環境を選ぶことができます。

### 1. Ollama

ターミナルから1行のコマンドを打つだけで、最も手軽にモデルを試すことができます。

* **公式サイト:** [ollama.com](https://ollama.com/)
* **実行コマンド:**

```bash
ollama run gemma4:e2b

```

* **プロンプト入力例:**

```
かぐや姫で俳句を書いて。
```

### 2. LM Studio

パラメータを細かく調整しながら検証したい場合におすすめです。

* **公式サイト:** [lmstudio.ai](https://lmstudio.ai/)
* **モデルのロード:** 検索バーから `Gemma 4 E4B` (API Identifier: `gemma-4-e4b-it`)をダウンロード
* **Context Length:** `12800` に設定 (タスクに応じて調整)
* **Max Concurrent Predictions:** 何個の並列処理を行うか

### その他の実行フレームワーク（ユースケース別）

より高度な要件や特定のハードウェア環境に合わせて、以下のツールも選択肢に入ります。

| フレームワーク | 特徴・最適なユースケース |
| --- | --- |
| **MLX** | **Appleハードウェア環境向け。** MacのApple Silicon(M1/M2/M3等)に特化して最適化されており、Mac上で高速に動作させたい場合に最適です。 |
| **vLLM** | **エンタープライズ性能向け。** 大量のリクエストを捌く高いスループットを持ち、本格的な推論サーバーを構築したい場合に適しています。 |
| **llama.cpp** | **フルカスタマイズ向け。** 多くのLLMアプリのバックエンドとしても採用されている軽量・高速なC++実装。細部まで自分好みにチューニングしたいエンジニア向けです。 |
| **Transformers** | **最新モデル・高精度重視。** Hugging Faceの標準ライブラリ。推論速度の最適化は弱いものの、幅広いモデルに即座に対応し、量子化なし(Full precision)で厳密に動かしたい場合に必須です。 |
